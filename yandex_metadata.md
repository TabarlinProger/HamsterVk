# Метаданные для Яндекс Игр — стратегия на основе анализа конкурентов

## Анализ конкурентов (11 игр жанра «стрелки»)

Проанализировав 11 популярных игр жанра, я выявил общие паттерны:

**Названия конкурентов:**
| Игра | Перевод | Приём |
|---|---|---|
| TapTap Стрелка | — | Тап + жанр (двуязычное) |
| Освободи стрелки | Free the arrows | Глагол + жанр |
| Стрелки: помоги этой семье | Arrows: help this family | Жанр + глагол |
| Помоги стрелке уйти | Help the arrow escape | Глагол + жанр + цель |
| Побег стрелок | Escape of arrows | Суть одним словом |
| Удалить стрелки | Delete the arrows | Глагол-действие |
| Arrow Escape: Стрелки лабиринт | — | Англ + рус + контекст |
| Разбери кубик | Disassemble the cube | Отдельная ниша |

**Ключевые выводы:**
1. **«Стрелки»** — это название самого жанра на Яндекс Играх, а не просто описание. Игроки ищут «стрелки» как категорию.
2. Глаголы в названии работают: освободи, помоги, убери, удали.
3. Двуязычные названия (рус + англ) — нормальная практика.
4. Некоторые игры вообще без осмысленного названия, только ID — и всё равно в топе.
5. Конкретные механики в описании не нужны — игроки этого жанра и так знают, что делать.

## Новая стратегия для «Тап Хомяк»

### 1. Название игры

**Русское:** Тап Хомяк
**Английское:** Tap Hamster

Альтернатива для A/B теста: **«Стрелки: Спаси хомяков»** или **«Хомяк Побег»**

Обоснование:
- «Стрелки» — название жанра, по нему ищут. Добавив «Стрелки» в название, мы встаём в одну выдачу с конкурентами.
- «Хомяк» — наше уникальное отличие от всех остальных «стрелок», главный крючок.
- «Тап» — глагол действия, как у лидера жанра (TapTap Стрелка).

**Рекомендуемый формат:** «Tap Хомяк» — коротко, и русское, и английское читается одинаково.

### 7. Ключевые изменения по сравнению с прошлой версией

| Было | Стало | Почему |
|---|---|---|
| «хомяк» без «стрелки» | **«стрелки»** как ключевое слово №1 | Так ищут жанр на ЯИ |
| Расписаны механики (трубы, порталы) | **Никаких механик** в описании | Игроки жанра и так знают, суть важнее |
| «без интернета/оффлайн» | **Убрано** | Неверная информация |
| Упор на «головоломка» | **Упор на «стрелки» + «хомяк»** | Конкуренты ранжируются по «стрелки» |
| Подробное описание механик | **Коротко, эмоционально, про пользу** | Пользователь ЯИ листает быстро |

### 8. Дополнительные рекомендации

1. **Первая иконка/скриншот** — должно быть сразу понятно, что это «стрелки» с хомяками. Иконка хомяка на игровом поле в клетку.
2. **Категория** — «Головоломки» (это основная категория). Если есть подкатегория «Логические» — туда.
3. **Видео-превью** — короткий гиф-ролик, где по тапу хомяк бежит через поле и выходит за край.
4. **A/B тест названия** — попробуй «Стрелки: Спаси хомяков» как альтернативу — это сразу ставит игру в один ряд с топовыми конкурентами.
